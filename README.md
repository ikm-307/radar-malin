# RADAR MALIN

Premier prototype du site Radar Malin : un calculateur gratuit du coût par page pour les consommables d'impression.

## Tester en local
Ouvrir `index.html` dans un navigateur. Aucun logiciel ni installation n'est nécessaire.

## Publier avec GitHub Pages
1. Dans le dépôt GitHub `radar-malin`, choisir **Add file > Upload files**.
2. Envoyer `index.html` et valider avec **Commit changes**.
3. Dans **Settings > Pages**, choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Attendre la publication et ouvrir l'adresse affichée dans la page Pages.

Le site est statique et ne nécessite ni serveur ni clé API.

## État du prototype
- Calculateur de coût par page fonctionnel.
- Estimation mensuelle et annuelle.
- Aucun prix marchand réel ni programme d'affiliation connecté.
- Les futures offres devront être vérifiées, datées et clairement signalées comme affiliées lorsqu'elles le sont.
